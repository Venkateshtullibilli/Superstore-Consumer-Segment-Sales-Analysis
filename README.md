# Superstore Consumer Segment Sales Analysis | Power BI

## 📌 Project Overview

This project focuses on analyzing sales performance for the Consumer Segment of a large superstore using Microsoft Power BI.

The objective was to calculate the total sales generated by the Consumer Segment using three different approaches and compare how each method solves the same business problem.

This project is part of my Data Analytics learning journey, where I am developing practical skills in Power BI, Power Query, DAX, and business analysis.

## 🏢 Business Scenario

I was given a business scenario as a Business Analyst for a large superstore.

The management team provided a dataset containing information about sales, orders, products, and customers.

The business team identified that sales in the Consumer Segment had not been performing as expected over the past few quarters.

Management wanted to know:

**What are the total sales generated by the Consumer Segment?**

## 🎯 Business Objective

- Identify sales records belonging to the Consumer Segment.
- Calculate the total sales generated by this segment.
- Solve the same business problem using three different approaches.
- Understand the differences between Power Query transformations and DAX measures.

## 🔍 Implementation – Three Different Approaches

I solved the business problem using three different approaches in Power BI.

### Method 1: Group By – Power Query

Used the **Group By** feature in Power Query to group sales records based on the `Segment` column and calculate total sales for each segment.

**Group By Configuration:**

| Setting | Value |
|---|---|
| Group By Column | Segment |
| New Column Name | Total Sales |
| Operation | Sum |
| Column | Sales |

**Process:**

1. Opened Power Query Editor.
2. Selected the `Segment` column.
3. Opened the Group By option.
4. Selected the Advanced grouping option.
5. Configured the new column name as `Total Sales`.
6. Selected `Sum` as the operation and `Sales` as the column.
7. Applied the changes to generate the summarized table.

This approach creates a summarized table containing total sales for each customer segment.

I then identified the Consumer Segment's total sales from the summarized results.

### Method 2: FILTER – DAX New Measure

Used the `FILTER` function to identify records belonging to the Consumer Segment and calculate their total sales.

```dax
Consumer Sales Filter =
SUMX(
    FILTER(
        Orders,
        Orders[Segment] = "Consumer"
    ),
    Orders[Sales]
)
```

**Explanation:**

- `FILTER` returns rows where the Segment is Consumer.
- `SUMX` iterates through the filtered rows.
- `Orders[Sales]` provides the sales values to be added.

### Method 3: CALCULATE – DAX New Measure

First, created a base measure to calculate total sales:

```dax
Measure_TotalSales =
SUM(Orders[Sales])
```

Then created a separate measure using `CALCULATE`:

```dax
ConsumerSales =
CALCULATE(
    [Measure_TotalSales],
    Orders[Segment] = "Consumer"
)
```

**Explanation:**

- `CALCULATE` modifies the filter context.
- `[Measure_TotalSales]` references the existing total sales measure.
- `Orders[Segment] = "Consumer"` applies the Consumer Segment filter.

## 📊 Analysis Results

The same business metric was calculated using all three approaches.
