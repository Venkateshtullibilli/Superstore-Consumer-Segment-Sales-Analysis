# Superstore Consumer Segment Sales Analysis | Power BI

## 📌 Project Overview

This project focuses on analyzing sales performance for the Consumer Segment of a large superstore using Microsoft Power BI.

The objective was to calculate the total sales generated by the Consumer Segment using three different DAX approaches and compare how each method solves the same business problem.

This project is part of my Data Analytics learning journey, where I am developing practical skills in Power BI, DAX, and business analysis.

## 🏢 Business Scenario

I was given a business scenario as a Business Analyst for a large superstore.

The management team provided a dataset containing information about sales, orders, products, and customers.

The business team identified that sales in the Consumer Segment had not been performing as expected over the past few quarters.

Management wanted to know:

**What are the total sales generated by the Consumer Segment?**

## 🎯 Business Objective

- Identify sales records belonging to the Consumer Segment.
- Calculate the total sales generated by this segment.
- Solve the same business problem using three different DAX approaches.
- Understand the differences between calculated tables and measures in Power BI.

## 🧮 DAX Implementation

I solved the business problem using three different approaches in Power BI.

### Method 1: GROUPBY – Calculated Table

Created a calculated table using the `GROUPBY` function.

This approach groups the filtered Consumer Segment records and calculates their total sales using `SUMX` and `CURRENTGROUP`.

```dax
Consumer Sales GroupBy =
GROUPBY(
    FILTER(
        Orders,
        Orders[Segment] = "Consumer"
    ),
    Orders[Segment],
    "Total Sales",
    SUMX(
        CURRENTGROUP(),
        Orders[Sales]
    )
)
```

### Method 2: FILTER – New Measure

Created a measure using the `FILTER` function to identify Consumer Segment records and calculate their total sales.

```dax
Consumer Sales Filter =
SUMX(
    FILTER(
        Orders,
        Orders[Segment] = "Consumer"
    ),
    Orders[Sales]
)
```

### Method 3: CALCULATE – New Measure

Created a measure using the `CALCULATE` function to modify the filter context and calculate total sales for the Consumer Segment.

```dax
Consumer Sales Calculate =
CALCULATE(
    SUM(Orders[Sales]),
    Orders[Segment] = "Consumer"
)
```

*Note: These are the documented example implementations based on the dataset structure. Ensure they match the exact formulas used in your Power BI file.*

## 📊 Analysis Results
